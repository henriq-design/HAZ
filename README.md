# HAZ

**Foco donde importa.**

Una pequeña utilidad nativa para macOS que he creado para dirigir la atención sobre la pantalla durante presentaciones, revisiones de diseño e inspección de interfaces, y también como apoyo visual para personas con baja visión o dificultades para leer detalles pequeños en pantalla. Permite ampliar, enfocar y guiar la mirada sobre áreas concretas sin cambiar de aplicación. Es un complemento visual: no sustituye las funciones de accesibilidad de macOS ni otras ayudas técnicas.

- Lupa con tres niveles de ampliación.
- Foco sobre áreas de la pantalla.
- Guías horizontales y verticales.
- Soporte multimonitor.
- Atajos de teclado.

Interfaz disponible en Español · English · 简体中文
